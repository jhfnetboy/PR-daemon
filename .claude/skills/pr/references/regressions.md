# 回归题库 —— 带**已知正确答案**的量具事故

> 借鉴 WikiSkill(2026-09-03 读的那篇)的一条:**技能改动必须由一个独立的东西 gate,
> 不能由提出改动的人自评。** 但他们的验证集是「回放整轮任务比分数」——那对我们不成立:
> 一轮 review 15–25 分钟,20 个 PR 改前改后要 13 小时,当不了门禁。
>
> 我们手上有更好的东西。`model-evals.sqlite` 里 **2185 条 run:1533 条记了误报、
> 1474 条记了漏检、176 条 summary 是我公开收回或更正自己**。这些不是分数,是
> **具体的读数错误 + 当时把它抓出来的那一手**。所以门禁的正确形态是**题库**,不是回放。

## 这个文件怎么用

**它有两个用途,第二个才是主要的:**

1. **给 `trials.md` 当门禁。** 一条在试的规则,结案时必须满足其一,否则**删除**:
   - 让题库里**某道题的答案变对**(它本来会答错,加了这条规则就答对了);或
   - 带来一道**新题**(它抓住了一个题库里还没有的失效模式)。

   「我觉得它有用」「这一轮我照做了」都不算。这一条是整个机制的承重点 ——
   `trials.md` 原来的 命中/空转/碍事 是**写规则的同一个 agent 事后自评**,
   那不是「弱一点的度量」,是**没有独立度量**。

2. **当覆盖图。** 每道题的「现在谁拦得住」一栏为空 = 一个**已知会发生、而规则里没人认领**
   的失效模式。那一栏的空格就是 skill 改进的待办清单,而且每一条都自带正确答案。

⛔ **执行 review 时不要读这个文件。** 理由和 `incidents.md` 同一条,而且那篇文章用消融
实验量过:执行者能读知识库时性能反而下降(63.7%→60.9%),因为会去**套结论**而不是真跑探针。
要判断「这条规则还成不成立 / 能不能改」时再读。

## 词表

- **答错**:当时我给出的结论
- **正确**:后来被实测/作者/Codex 证明的答案
- **抓手**:把它翻出来的那一次具体操作(题库的价值在这一栏 —— 它是可复用的)
- **谁拦得住**:`SKILL.md` 或 memory 里现在有没有一条规则会拦下它;空 = 无人认领

## R-01 处方过严:行尾锚禁止了正当尾注

- **题**:给台账开一条判据 `grep -cE '^- \[x\] FU-.*done=PR#[0-9]+ *$'`,用来查「`[x]` 数 == `done=PR#数字` 数」。
- **答错**:加了 ` *$` 行尾锚才算严谨,发出去了。
- **正确**:锚**从未承重** —— `[0-9]+` 早就排掉了字面的 `done=PR#n`;它唯一的效果是把
  `done=PR#142(仅子进程支)` 这种正当尾注判红。对方已把我的写法抄进台账表头当规则。
- **抓手**:**拿已知坏态逐格删限定再跑** —— 去掉锚,坏态仍然红 ⇒ 那一格不承重,是误报源。
- **来源**:Agent24#144(2026-09-02),我公开撤回。
- **谁拦得住**:memory `feedback_test_the_criterion_on_the_known_bad_state`。**SKILL.md 里没有。**

## R-18 造出来的「坏状态」其实不坏,两侧都红

- **题**:要验证 `rebuild` 末尾那句 FTS5 `'rebuild'` 承不承重,得先造出「FTS 索引与 `docs` 对不上」的坏状态。
- **答错**:往 `docs_fts` 里塞一条 `docs` 中**根本不存在**的 rowid 的倒排项。跑出来**两侧都红**
  (真源码也红) —— 差一点读成「这条测试写坏了」或者「代码有问题」。
- **正确**:`search()` 里有 `join docs d on d.rowid = f.rowid`,**没有对应 `docs` 行的孤儿项根本进不了结果集**。
  坏状态压根没造出来。挂到一个**会被 `delete from docs` 之后复用的** rowid 上才是真的
  —— 那才是作者注释里描述的场景。
- **抓手**:**给「造状态」这一步配它自己的对照** —— 一行 `assert_eq!(hits(&ix, "幽灵词"), 1, "前置:坏状态必须真的可观测")`。
  是它当场把我拦下来的:红在**前置**那一格而不是结论那一格,两者的区别就是全部信息。
  ⚠️ 「两侧都红」和「测试写错了」外观相同;**红在哪一格**才分得开。

## 怎么加新题

只加**有已知正确答案**的:我公开收回过、被作者/Codex 实测推翻过、或事后被证明读数是假的。
「我觉得这里可能有问题」不进题库。每条必须填「抓手」——**没有抓手的题是故事,不是题**。

来源可以从 DB 捞:

```bash
sqlite3 reviews/model-evals/model-evals.sqlite "
SELECT repo||'#'||pr_number||'  '||substr(finished_at,1,10)||char(10)||replace(summary,char(10),' ')
FROM model_review_runs
WHERE summary LIKE '%更正%' OR summary LIKE '%收回%' OR summary LIKE '%撤回%' OR summary LIKE '%证伪%'
ORDER BY id DESC;"
```

建库时这条命令返回 176 条,只转化了 15 条 —— **剩下的是存量,不是没有**。
