# 试用中的 skill 改动 —— 每次 review 记一行，攒够了再结案

Jason 2026-09-02 定的做法：**新加的步骤先当「试用」，不当「已确立」。**
每次 review 的自评块里给每条试用项记一行，攒够数据再决定 **保留 / 删除 / 微调**。

## 为什么要有这个文件

SKILL.md 一直在长（1114 行），**每一条都是某次事故买来的，但没有任何一条被回收过**。
一条从不命中的规则和一条有用的规则在文件里长得一模一样 —— 读的人分不出来，
而它照样占据注意力、照样要被遵守。

所以试用项要满足三件事，缺一条就不算试用而是「又加了一条」：

1. **假设**：它应该抓住什么。写成一句可证伪的话。
2. **证伪判据**：什么观测算它**没有**挣到位置。必须是具体的观测，不是「感觉没用」。
3. **结案规则**：跑够 N 次 review 或到期日之后，**必须**给出结论并落笔。

⛔ **默认结局是删除。** 数据不够、或者一直是「空转」，就删掉 —— 不是「再观察观察」。
**举证责任在这条规则身上**，不在删它的人身上。

## 记录用词（只用这五个，与 `SKILL.md` 自评块那一节逐字一致）

| 记号 | 含义 | 判据 |
|---|---|---|
| **命中** | 这一轮因为它，我做了/发现了原本不会做/不会发现的事 | 要能写出那件事是什么 |
| **空转** | 我照做了，但结论一个字都没变 | 照做了才叫空转 |
| **碍事** | 它让我花了时间却把注意力从更重要的事上引开，或逼出了一个错误结论 | 要写出被挤掉的是什么 |
| **未执行** | 我没照做 | 不是空转；要写为什么没做 |
| **N/A** | 这一轮结构上不适用 | 如 2-round 路径不跑 R3，T2 记 N/A |

⚠️ **「空转」不是失败，一条守卫大多数时候空转是正常的。** 判据是**结案时**看：
全程 0 次命中 = 删；命中率低但每次命中都拦住了真东西 = 保留；命中的都是它顺手带出来的
副产品而不是它本身要抓的 = 微调（改判据，不是改措辞）。

## T2 — R3 产物的机械核验（「不许静默跳过一个 reviewer」）

- **加入**：2026-09-02（借鉴 Adversarial Review skill 的 Step 4）
- **位置**：SKILL.md `Step 5b` 的 R3 段
- **假设**：把「Codex 到底跑没跑」从印象改成**产物上的两个判据**（非空 + 自报模型），
  能挡住「兜底模型的输出被当成 Codex」和「超时空文件被读成『Codex 没意见』」。
- **它要解决的实际问题**：`codex_pk.sh` 曾经静默回落到 DeepSeek；
  `exit 143` + 空输出 + 空 stderr 与「Codex 跑了但没意见」**读起来一模一样**。
  记忆里已有这两条，但**不是 skill 里的一步**，靠我记得。
- **证伪判据**：
  - 结案时统计，**没有任何一次**这两个判据改变过我对 R3 的记述（既没抓到降级、
    也没抓到空产物）——说明它在重复 `codex_pk.sh` 自己已经保证的事；
  - 或者它误报（判成「没跑」而实际跑了）**≥1 次** —— 误报比漏报更要紧，
    因为它会让我去补跑一轮不需要的 Codex。
- **结案规则**：攒满 **10 次跑过 R3 的** review，或到 **2026-09-16**。
  （2-round 路径不跑 R3，那些轮次不计数，记「N/A」。）
- **2026-09-02 微调（证伪判据「误报 ≥1 次」已触发）**：反向判据原为 `grep -icE "deepseek|kimi|glm" "$OUT"` 扫**全文**，
  而 `codex_pk.sh` 的输出里包含 **prompt 回显** —— 只要我在 prompt 里提到 DeepSeek 的 finding，
  这一格就命中，一次真 Codex 会被判成兜底（SuperPaymaster#416 实测）。
  **改为只看 `codex_pk.sh` 自己打的首行 `CHALLENGER:`**（它本来就为此存在，脚本头写着
  「The first line of the output names the challenger that actually ran」）。
  正向的两格（非空 / 自报 codex）不变。这次是微调判据，不是删掉这条试用。
