# 试用中的 skill 改动 —— 每次 review 记一行，攒够了再结案

Jason 2026-09-02 定的做法：**新加的步骤先当「试用」，不当「已确立」。**
每次 review 的自评块里给每条试用项记一行，攒够数据再决定 **保留 / 删除 / 微调**。

## 为什么要有这个文件

SKILL.md 一直在长（1114 行），**每一条都是某次事故买来的，但没有任何一条被回收过**。
一条从不命中的规则和一条有用的规则在文件里长得一模一样 —— 读的人分不出来，
而它照样占据注意力、照样要被遵守。

所以试用项要满足三件事，缺一条就不算试用而是「又加了一条」：

1. **假设**：它应该抓住什么。写成一句可证伪的话。
2. **证伪判据**：什么观测算它**没有**挣到位置。必须是具体的观测，不是「感觉没用」。
3. **结案规则**：跑够 N 次 review 或到期日之后，**必须**给出结论并落笔。

⛔ **默认结局是删除。** 数据不够、或者一直是「空转」，就删掉 —— 不是「再观察观察」。
**举证责任在这条规则身上**，不在删它的人身上。

## ⛔ 结案的硬门禁 —— 自评不算数（2026-09-03 加）

> 借鉴 WikiSkill 的一条：**技能改动要由一个独立的东西 gate，不能由提出改动的人自评。**

下面那张 命中/空转/碍事 表有一个结构性缺陷，必须先说清楚：**它是写这条规则的同一个 agent
事后给自己打的分。** 那不是「弱一点的度量」，是**没有独立度量**。所以从今天起，结案时
除了那张表，还要过一道**外部判据**：

**一条试用项要留下，必须满足其一，否则删除：**

1. 让 [`regressions.md`](regressions.md) 里**某道题的答案变对** —— 那道题本来会答错，
   加了这条规则之后答对了；或
2. 带来一道**新题** —— 它抓住了一个题库里还没有的失效模式，且那个失效**真的发生过**
   （有 PR 号、有当时的错答、有把它翻出来的抓手）。

题库里的答案是**过去的我在对抗条件下写下的**，且已被作者 / Codex / 实测钉死，
不是现在的我为了保住一条规则而给的。这就是它比自评强的全部原因。

「我觉得它有用」「这一轮我照做了」「它让我更系统」——**都不算**。

## ⛔ 一次只上一条（2026-09-03 加）

新试用项**一次只加一条**，上一条结案之后再上下一条。

理由是我们正踩着的坑：**T1 / T2 / T3 是同一个 commit 一次加上去的**，三条同时在跑，
所以任何一轮 review 的质量变化都**归因不到具体哪一条**。这三条的观测记录因此天生带
混淆，结案时只能各自单独看命中记录，不能用「这段时间 review 质量如何」当证据。
这个事实必须在它们结案时写进结论里。

每条试用项还要记下**引入它的 commit sha**（见各节的「加入」行），
这样「改了什么 → 记录了什么 → 结论是什么」是一条能追的链，而不是三份各自为政的文档。

## ⛔ 被删掉的也要留档 —— 失败是复利的种子（2026-09-03 加）

「已结案」区**不是墓地，是资料**。一条规则被删掉时，必须写清**它为什么不成立**，
而不是把整节抹掉。

理由：默认结局是删除，而删干净之后「这个想法为什么行不通」也没了 —— 同一个念头过两周
会原样再冒出来，然后再花十轮观测把它否掉一次。WikiSkill 那篇里最有说服力的例子正好是
这个：Iteration 0 被拒的 `goal-directed-action` 留了记录，成了 Iteration 1 提出更具体的
`break-repetition-loop` 并通过的依据。**被否决的提案是下一个提案的输入。**

结案时那一节要写满四样：**结论**、**依据的观测次数**、**改动本身被保留/删除/微调了什么**、
以及（若删）**下次什么条件下值得重提**。

## 记录用词（只用这五个，与 `SKILL.md` 自评块那一节逐字一致）

| 记号 | 含义 | 判据 |
|---|---|---|
| **命中** | 这一轮因为它，我做了/发现了原本不会做/不会发现的事 | 要能写出那件事是什么 |
| **空转** | 我照做了，但结论一个字都没变 | 照做了才叫空转 |
| **碍事** | 它让我花了时间却把注意力从更重要的事上引开，或逼出了一个错误结论 | 要写出被挤掉的是什么 |
| **未执行** | 我没照做 | 不是空转；要写为什么没做 |
| **N/A** | 这一轮结构上不适用 | 如 2-round 路径不跑 R3，T2 记 N/A |

⚠️ **「空转」不是失败，一条守卫大多数时候空转是正常的。** 判据是**结案时**看：
全程 0 次命中 = 删；命中率低但每次命中都拦住了真东西 = 保留；命中的都是它顺手带出来的
副产品而不是它本身要抓的 = 微调（改判据，不是改措辞）。
