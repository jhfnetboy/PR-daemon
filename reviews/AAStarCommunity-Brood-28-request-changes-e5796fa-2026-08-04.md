Any downstream repo (this skill ships via `install.sh` into arbitrary repos) whose trunk isn't literally named `main`/`master`/`develop`/`release*`/`hotfix*` gets zero protection from this check. Codex R3 independently confirmed, fed only the verbatim source: "only matches a literal built-in trunk list and never consults `--protect`/`PROTECTED`... `is_protected(head_ref)` applies only to the PR head branch, not the merge target."
