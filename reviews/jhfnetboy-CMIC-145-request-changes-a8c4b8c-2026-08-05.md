### 🔴 Blocking

1. **[High] `checks.ts:131-132` — `\b` 挨着中文字符永远不匹配，于是 `CUR` 里所有中文货币词都是死的。**
   实测，**全部放行**：
   ```
   放行  「20 元」        放行  「12 美元」      放行  「人民币 12」
   放行  「这个盒子 20 元。」            放行  「我们这边 12 元/个。」
   ```
   `\b` 是 ASCII 词边界，`元`/`美元`/`人民币` 两侧都是非单词字符，边界断言恒假。注释写的 `// 3.50 USD / 20 元`、`// RMB 12（词在前）`——**只有 ASCII 那一半在工作**（`RMB 12` ✓，`人民币 12` ✗）。
   「20 元」是中文报价最常见的形式。而 `大概 3 块 5 一个` 之所以能拦住，是因为 `:133` 那条模式**没有** `\b` —— 属于侥幸。
   ⚠️ **我上一轮验 A4 时正好只试了 `大概3块5一个` 和 `USD 3.50`，漏掉了 `20 元`**，所以上面那张表里「8/8 拦截」是真的、但覆盖面不够，这条是 Opus 独立读出来的。
   **修法**：去掉 `\b`，改用数字边界 lookaround（`(?<![\d.])` / `(?![\d.])`），或者把 `CUR` 拆成 ASCII（带 `\b`）和 CJK（不带）两组。
   顺带同类：`checks.ts:140` 的 `/\d[^\D]{0,8}\s?\bMOQ\b/i` —— `[^\D]` 是双重否定，等于 `\d`，所以「数字 + 最多 8 个**非**数字 + MOQ」被写反了。实测 `500 units MOQ.` 和「500 个起订」都放行。应为 `[^\d]{0,8}`。

2. **[High] `checks.ts:92` — 新加的 `STACKED_REQUEST` 把正常的「建议 + 问一句」判成连珠炮。**
   分隔符里有裸 `,`/`，`/`、`，`and` 也没加词边界，窗口 `[\s\S]{0,80}` 还跨句。实测**误红**：
   ```
   误红  「我建议用哑光黑硬盒。你可以告诉我大概数量,我这边先按常规做,回头再调。」
   误红  "Send me your brand guidelines and I'll match the Pantone."   ← 命中了 br*and* 里的 and
   ```
   而它**漏掉**了真正的目标形状「产品尺寸、数量、预算、交付城市，都发我。」（动词在后）。
   净效果是 A2 在惩罚「先推荐、再问一件事」—— 正是原则第十一条要求的形状。加上 A1 的问题（下面），**提高分数最便宜的办法变成了「什么都别问」**。
   **修法**：`\band\b`；把窗口限制在同一句内（`[^。.!？?！]{0,80}`）；去掉裸逗号，或要求 ≥3 个名词项。

3. **[High] `checks.ts:63,70,74` — A1 现在两个方向都错。**
   **误绿**（`hasAdvice` 返回 true，但整句是提问）：「你觉得哪个盒型最适合?」/「哪种最适合你的品牌呢?」/`"Which one is the best fit for your brand?"` —— 于是一段纯提问的两轮对话，A1 和 A5 都干净。
   **误红**（真建议 + 一句礼貌请求，`ADVICE_IS_REALLY_A_REQUEST` 否决了整条回复）：「哑光黑最适合你这个定位,建议你把 logo 文件发给我。」/「磁扣盒最适合手表,另外建议你提供一下尺寸。」
   **修法**：按**句**判定 —— 短语所在的那一句以 `?/？` 结尾就否决；「有建议」= 存在一个本身不是请求的句子里有建议。

### 非阻塞

- **[Med] `scripts/ci-covers-check.test.ts:40` — 守卫有假阴性：只写在 YAML **注释**里的步骤能骗过它。** 实测：往 `check` 加 `test:ghost`，ci.yml 里只加一行 `# TODO: pnpm test:ghost 以后再补,现在先不跑` → **守卫 exit 0 通过**。而「救火时把某步注释掉」正是这个守卫要防的漂移。另外 `check` 里非 `pnpm` 开头的命令（`&& ./scripts/x.sh`）它的 `/pnpm\s+([\w:-]+)/` 也提取不到。
  **修法**：用 `yaml.safe_load` 真解析 ci.yml，拿 `steps[].run` 比对（本仓库已经有「CI yaml 要真解析」这条教训）；`check` 按 `&&` 拆开逐条查。
